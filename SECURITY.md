# Security Policy

## Supported Versions

We actively maintain the latest version of the Mergington High
Extra-Curricular Activities website.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately
using the repository's private vulnerability reporting form, or email
the tech team at techclub@mergingtonhigh.example.edu.

Please do not open a public issue for security problems. We will
review all reports promptly and keep you updated on the progress.
